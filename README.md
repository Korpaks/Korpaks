## Engineering approach

- Assert meaningful user outcomes and API contracts—not just successful clicks or status codes.
- Keep tests independent, repeatable, and responsible with explicit data isolation and cleanup.
- Prefer stable locators, typed helpers, reusable fixtures/clients, and environment-driven configuration.
- Make CI failures diagnosable through traces, screenshots, videos, request/response logs, and reports.
- Test negative paths safely without destructive or security-sensitive behavior.
