## How I approach quality

- Assert meaningful user-visible outcomes and API contracts—not just successful clicks or status codes.
- Keep stateful tests isolated, repeatable, and responsible.
- Prefer stable locators, typed helpers, reusable fixtures, and explicit cleanup.
- Design CI failures to be diagnosable through traces, screenshots, videos, and reports.
- Use negative testing safely, without destructive or security-sensitive behavior.
